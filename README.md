# Ростов-гид

Агент-справочник по 8860 местам Ростова-на-Дону (снимок OpenStreetMap) — MVP с веб-интерфейсом.
Спросите словами, даже если не помните названия: «забыл, как называется кафе, — там были пельмени».
Агент найдёт место по смыслу, покажет каждый свой шаг в реальном времени и отметит найденное на карте.

Стек: **Python 3.12, Google ADK** (агент, сессии, плагины), **LiteLLM → LM Studio** (локальные `qwen3.5-4b`
и `bge-m3`), **Qdrant** (гибридный поиск), **FastAPI + SSE**, фронтенд на ES-модулях и Leaflet без сборки.

## Что умеет

- **Форма вопросов вместо файла** — чат с историей, несколько чатов на пользователя.
- **Видно, как агент думает** — по SSE в реальном времени приходят рассуждения модели, вызовы
  инструментов с аргументами, результаты (сколько нашлось, кто нашёл — смысл или слова), затем ответ
  по токенам. После ответа ход мысли сворачивается в строку «Рассуждал 7,6 с · 1 инструмент · 2 шага».
- **Поиск по смыслу** — «пельмени» находит «Пельмень», «Пельмешку» и кафе с русской кухней;
  «снять наличные» — банкоматы. Гибрид плотных векторов и BM25 в Qdrant.
- **Учёт контекста** — помнит разговор («а до скольки работает второе?»), показывает, сколько окна
  модели занято, и сворачивает старую историю в сводку, когда окно подходит к пределу.
- **Многопользовательский режим** — регистрация и вход, данные изолированы; вопросы встают в очередь
  к модели, каждый видит свою позицию; можно остановить ответ; перезагрузка страницы не теряет поток.
- **Карта** — найденные места пронумерованы так же, как карточки; точку «я здесь» можно поставить
  кликом, и «рядом со мной» считается от неё; статус «открыто до 21:00» считается по текущему времени.

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и [LM Studio](https://lmstudio.ai/) с двумя моделями:

```bash
lms server start
```

```bash
lms load qwen3.5-4b --context-length 16384 -y
```

```bash
lms load text-embedding-bge-m3 -y
```

Затем одна команда:

```bash
uv run rostov-guide
```

Откройте http://127.0.0.1:8000, зарегистрируйтесь и спросите что-нибудь. При **первом** запуске
векторный индекс строится в фоне ~4 минуты (LM Studio считает эмбеддинги 8860 мест); интерфейс
показывает прогресс, агент тем временем ищет обычными фильтрами. Дальше индекс поднимается из
кеша за секунды.

Другая модель или облако — переменные в `.env`, образец в [.env.example](.env.example).

## Команды

| Команда | Что делает |
|---|---|
| `uv run rostov-guide` | веб-приложение |
| `uv run rostov-guide index --rebuild` | пересобрать векторный индекс |
| `uv run rostov-guide eval-search` | сравнить поиск: смысл / слова / гибрид |
| `uv run rostov-guide eval-agent -n 3` | прогнать сценарии агента на живой модели |
| `uv run pytest` | 62 теста (без сети и без модели) |

## Как устроено

Подробно, со схемой и обоснованием каждого решения, — в [docs/architecture.md](docs/architecture.md).
Коротко:

```
src/rostov_guide/
  agent/      LlmAgent ADK: инструкция, 4 инструмента, плагины (журнал, ошибки → наблюдения), оценка
  search/     документы для индекса, эмбеддинги с кешем, BM25, Qdrant + RRF, оценка поиска
  places/     справочник в памяти, геокодинг по адресам базы, часы работы, словарь видов и кухонь
  web/        FastAPI: вход, чаты, прогоны с очередью и SSE, перевод событий ADK для интерфейса
  static/     интерфейс: чат, ход мысли, карточки, карта
```

## Качество

**Поиск** — 20 размеченных запросов, `eval-search`:

| Режим | P@5 | Hit@1 |
|---|---|---|
| только смысл (bge-m3) | 0.85 | 0.90 |
| только слова (BM25) | 0.87 | 1.00 |
| **гибрид** | **0.92** | **0.95** |

**Агент** — сценарии с эталоном, посчитанным по базе, `eval-agent` (результаты — в `runs/agent-eval-*.json`):

| Метрика | Значение |
|---|---|
| сценарии × повторы | 9 × 3: подсчёт, ближайшее к адресу и к ориентиру, «забыл название», блюдо, сеть, два уточнения по памяти («а какой у неё телефон», «а какая из них ближе»), посторонний вопрос |
| pass@1 | **1.00** — 27 из 27 прогонов (нижняя граница Уилсона 95%: 0.88) |
| pass^3 | **1.00** — 9 из 9 сценариев прошли во всех трёх повторах (граница Уилсона: 0.70) |
| время ответа | 10,8 с в среднем на сценарий |
| шагов модели | 2,56 в среднем, лимит — 8 |
| токены | ~6,6k на входе, ~0,6k на выходе; стоимость 0 ₽ — модель локальная |

Сценариев немного, поэтому вывод осторожный: на типовых вопросах агент надёжен, но набор надо расширять,
прежде чем говорить о качестве в целом. Эталоны считаются по базе, а не захардкожены.
Два сценария появились после финальной перепроверки, которая нашла и исправила четыре дефекта —
разбор в [docs/architecture.md](docs/architecture.md#что-нашла-перепроверка).
